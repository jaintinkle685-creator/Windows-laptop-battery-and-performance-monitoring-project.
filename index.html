How to use AOA
1. Click Download AOA for Windows above.
2. Open the latest AOA Windows release and download the Windows package.
3. Extract the downloaded package to a folder on your Windows laptop.
4. Launch AOA using the included Windows launcher/application.
5. AOA starts its local monitoring service automatically and opens the live dashboard in Chrome.
6. The dashboard then displays the data from that user's own Windows laptop.
Windows only: Live hardware telemetry runs locally on the user's Windows computer. The public website is the download and information page; it does not directly access hardware through GitHub Pages.
