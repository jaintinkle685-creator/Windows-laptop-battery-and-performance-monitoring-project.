ANALYSIS OF ALGORITHMS • PROJECT SHOWCASE

Laptop Battery Usage Optimizer

Our project combines live laptop telemetry with algorithmic decision-making to understand battery usage, rank costly workloads and recommend safer power-saving actions.

AOAAlgorithm-driven
Battery Intelligence
⇢ HOW THE SYSTEM WORKS
01CollectBattery • CPU • RAM • Power • Display
02ProcessValidate • Normalize • Track history
03AnalyzeScore • Rank • Detect inefficient states
04DecideGreedy selection of useful actions
05ExplainClear recommendations with estimated saving
◆ PROJECT OBJECTIVES
  • Continuously monitor battery and system resources.
  • Detect real Windows brightness and refresh-rate changes.
  • Visualize battery, power and workload trends smoothly.
  • Rank estimated power consumers from highest to lowest.
  • Generate explainable battery-saving recommendations.
  • Demonstrate algorithmic efficiency through live data.
⌘ KEY ALGORITHMS
GreedyChooses the highest-value safe action first.
Sliding WindowKeeps recent samples for live trends.
Running AverageUpdates power statistics without rescanning history.
Sorting / RankingOrders power-consuming processes.
Weighted ScoreCombines live system factors into /100 efficiency.
Rule-Based DecisionTurns detected conditions into explanations.
∑ ALGORITHM COMPLEXITY TIME + SPACE
Rolling sampleO(1) amortizedO(N) space
Running averageO(1)O(1) space
Efficiency scoreO(1)O(1) space
Greedy selectionO(A log A)O(A) space
Power rankingO(P log P)O(P) space
Canvas renderingO(N)O(1) extra

N = retained samples • A = candidate actions • P = active processes. The project keeps history bounded so live monitoring remains responsive.

✓ ADVANTAGES
  • Live and explainable analysis.
  • Efficient rolling calculations.
  • Clear greedy recommendations.
  • Useful visual dashboard for demonstration.
! LIMITATIONS
  • Windows telemetry depends on supported hardware fields.
  • Per-process watts are estimates.
  • What-If controls do not modify Windows settings.
  • Some GPU fields may show N/A.
↗ FUTURE SCOPE
  • Long-term battery history.
  • ML-based runtime prediction.
  • More vendor-specific telemetry.
  • Optional automatic optimization.
